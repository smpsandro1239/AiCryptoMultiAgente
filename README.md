# Multi-Agent Trading Framework (MATF)

A modular, AI-native, event-driven trading framework built around autonomous agents.

## Features
- Multi-agent architecture (Regime, Scanner, Risk, Supervisor, Execution)
- Async event bus
- Backtester with slippage & commissions
- CCXT live/paper trading
- YAML-configurable policies
- Semantic memory for decisions
- Indicators & scanners included
- Full metrics & reporting module

## Quick Start

```bash
pip install -r requirements.txt
python examples/backtest_example.py
```
